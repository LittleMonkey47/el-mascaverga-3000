Crear y usar una base de datos

CREATE DATABASE tienda;
USE tienda;
CREATE DATABASE crea el contenedor. USE le indica a MySQL que las siguientes sentencias trabajan sobre esa base.

Crear una tabla

CREATE TABLE productos (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nombre VARCHAR(100) NOT NULL,
  descripcion TEXT,
  precio DECIMAL(10,2) NOT NULL,
  fecha_ingreso DATE
);

Cada línea define una columna: nombre, tipo de dato y restricciones opcionales como NOT NULL o PRIMARY KEY.
