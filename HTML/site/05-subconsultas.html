Subconsultas

← volver

Subconsulta en el WHERE

SELECT nombre, precio
FROM productos
WHERE precio > (
  SELECT AVG(precio) FROM productos
);

La subconsulta calcula el precio promedio; la consulta externa muestra los productos que superan ese promedio.

Subconsulta en el FROM

SELECT caros.nombre
FROM (
  SELECT * FROM productos WHERE precio > 100
) AS caros;
5
La subconsulta se ejecuta primero y su resultado se usa como si fuera una tabla temporal para la consulta externa.
